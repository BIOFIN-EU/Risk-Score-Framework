# BIOFIN-EU Risk Framework
🇪🇺
*"This service was created in the context of BIOFIN-EU project (https://biofin-project.eu/). BIOFIN-EU has received funding from the EU’s Horizon Europe research and innovation programme under Grant Agreement no. 101135476."*

The Biofin Risk Score Framework is an API to support biodiversity-informed financial decision-making.
This web API service is intended to provide the basic endpoints for calculating the biodiversity risk scores of a given region, with explanaiability and transparency. These are also being used as part of the Biofin NBS Dashboard.
